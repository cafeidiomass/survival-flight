# LET'S TRAVEL! — Survival Challenge

**The Cheap Flight Isn't So Cheap** is a classroom-ready interactive English practice game.

## Play
Open `index.html` in a modern browser. No installation, backend, or internet connection is required. The optional Google Font uses internet when available, but local fallback fonts work offline.

## How it works
1. The student reads a $350 flight offer.
2. The student asks natural-language questions in English in the chat box. The booking agent recognizes questions about baggage, seat choice, layover, date changes, cancellation, and refunds, and reveals the answer. Speech synthesis reads responses aloud when the browser supports it.
3. After all six topics, the student decides whether to book and writes an explanation.
4. The activity reveals an example $430 fare after selecting a $55 bag and a $25 seat.

## Teacher notes
- Beginner: use question hints and sentence starters; ask students to speak before typing.
- Intermediate: request full questions and answers with *because*.
- Advanced: discuss trade-offs, refund policy, and flight comparisons.
- Agent responses and invented exercise fees can be customized in `script.js` (`topics` array).
- This is a scripted simulation, not a real airline price quote or an AI chatbot.
